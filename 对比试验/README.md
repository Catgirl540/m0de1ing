# 对比与消融实验

本目录用于复现当前正式模型的基准对比、模块消融、统计检验和论文图表。

在项目根目录运行：

```powershell
python 对比试验/run_comparison.py
```

实验严格沿用 `two.py` 和 `four.py` 中的“训训训验训测”划分。参数选择只使用训练集和验证集，所有模块贡献与策略泛化结论均使用测试集计算。

主要输出包括：

- 问题二负荷与光伏基准/消融指标；
- 问题四实时电价基准/消融指标；
- 问题三、四MPC策略经济性对比；
- 问题三新增预报时刻的边际信息价值分析；
- 配对Wilcoxon显著性检验；
- 各组成模块的正、负边际贡献率；
- 7张300 dpi论文图片；
- 可直接加入论文的实验设置、结果分析与综合评价。
