⭐ 这套东西的优势在哪（对比"无体系裸打"）

数模竞赛的失败大多不是"不会做"，而是死在可预防的事故上。本体系每一件工具都对应一种已知死法的疫苗——且全部经过 2024C 真题全流程实战验证。

常见死法（无体系裸打）本体系的机制化防御
图表默认样式、中文爆格、字小成团图表引擎 v2：18 种科研图型、低饱和色盲安全配色、constrained_layout 防越位、字号按 15cm 版面物理校准、缺字自动预警
文图数字对不上（评委扣分重灾区）单一事实源：结果 CSV → 图表 → figure_index 登记 → check_figures 三方一致 + 摘要数字对账
求解器给啥信啥，错了毫无察觉独立重算铁律：目标值按解重算比对；消融实验量化每条约束的真实约束力
队友成果口径漂移、建模代码两张皮协作接口 + 总揽审查：投递规范 → /审查 三条对抗线（题意/一致/上限）→ 意见单 P0 清零才进论文

长会话 AI 空转、token 烧完活没干完分层装载 + 检索上限 + 空转熔断（AGENTS.md §2，AI 会话自动遵守）
赛完就忘，同一坑明年再踩复盘 → 经验库 → CHANGELOG 闭环：同类坑出现 2 次必须固化进模板/工具/规范

⑤ 和 AI 怎么配合（为什么它不再空转）

说什么 → 用什么 "审题/选题" → /审题；"用什么模型" → /建模；"写代码/跑结果" → /建模 对应 03 卡； "画图" → /绘图；"写第X章" → /写章节；"写摘要" → /摘要； "检查" → /质检；"审队友成果/找不一致" → /审查； "复盘" → /复盘；"找资料" → 问 01_资料库 索引。
三条 token 纪律（已写死在 AGENTS.md） ① 分层装载：AI 只读当前任务要的那张角色卡，禁止通读全部文档； ② 预算上限：大文件只读片段、搜索 ≤2 轮、文献深读 ≤5 篇、命令重试 ≤2 次； ③ 空转熔断：连续 2 次动作没新信息，必须换策略或问你。
人只做判断 选题方向、方法取舍、审美验收、数值口径——AI 给选项，你签字。 AI 只许用素材里的数字，缺数留【待填】，禁止编造。
红线（竞赛合规） AI 只能辅助，队对原创性/真实性/准确性负全责（2026 参赛规则第 6 条）； AI 生成段落必须人工重述改写；如实说明 AI 使用情况。
每次 AI 会话结束会把有效经验 ≤5 行写进 90_复盘/经验库.md—— 这是体系自我迭代的燃料；赛后复盘（/复盘）保证同类坑出现 2 次就被固化进模板/工具/规范。

⑦ 常见问题

图怎么画才专业？

禁止 matplotlib 默认样式。CSV 交接（UTF-8、首行表头）→ python tools/make_chart.py <图型> --data xxx.csv， 出 PNG 300dpi + PDF 双格式；流程图用 make_flowchart.py。画完登记 figure_index.csv 并跑 check_figures.py。

摘要什么时候写？

T+52–60h，全场最贵的 8 小时，用 /摘要 三轮打磨（骨架轮 → 量化轮 → 删字轮）。憋到最后一小时 = 主动放弃获奖线。

中途产生一堆临时文件怎么办？

试验图进 tools/output/；赛后杂件进 99_归档/日期_主题/，只进不改。不要在根目录散放。

比赛忘了某个阶段的标准？

顺序：00_标准/交付物标准.md（标准）→ WORKFLOW.md（节奏）→ 本页（导航）。三者冲突以标准为准。

想找某个算法/模板/往年优秀论文？

先查 01_资料库/高星开源项目索引.md（标了每个仓库什么时候用），再上外网——省 token 也省时间。
