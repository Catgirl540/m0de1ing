# 模型卡片 · 模型I：多季种植计划 MILP（问题一）

> 对应问题一（2024–2030 最优种植方案，case1 滞销 / case2 五折）。角色卡 02 产出。

## 1. 回答题目哪一问

问题一：在参数不变假设下，给出两种超产处理情形下 7 年逐年逐季的最优种植方案，并回填 result1_1 / result1_2。

## 2. 模型类型

混合整数线性规划（MILP），scipy.optimize.milp（HiGHS）精确求解。

## 3. 核心假设（含合理性论证）

| # | 假设 | 合理性 | 影响方向 |
|---|---|---|---|
| A1 | 价格取题给区间中值 | 区间无分布信息，中值为无偏估计 | 偏高/偏低对称，不影响结构 |
| A2 | 预期销售量 = 2023 总产量（Σ面积×对应亩产量），每季封顶 | 题面"相对2023保持稳定"的最直接口径 | 若实际口径为"年销量"则总收入上偏 |
| A3 | 最小种植面积 0.5 亩（露地）/0.3 亩（大棚），单作物单季 ≤8 地块 | 量化"面积不宜太小/不能太分散" | 约束越紧总收入越低 |
| A4 | 重茬约束含 2023→2024 交界 | "连续重茬"的自然语义 | 排除部分 2024 可行方案 |
| A5 | 豆类=类型含"豆类"（1–5,17–19），滑窗 2024–2026…2028–2030 | "三年内至少一次"的滑动窗口口径 | 窗口越严豆类面积越大 |
| A6 | 大棚第二季按当年归档 | 记账口径统一 | 无 |

## 4. 输入 / 输出

- 输入：`03_代码/A1_*.csv`、`A2_*.csv`（已清洗）；清洗规则：过滤表尾注释行、单价区间取中值。
- 输出：
  - `03_代码/F01_历年收入对比.csv`（列：年份, 滞销方案收入, 五折方案收入）
  - `03_代码/F02_面积结构.csv`（列：年份, 作物类型, 面积亩）
  - `03_代码/plan_case1.csv`、`plan_case2.csv`（列：年份, 地块, 季次, 作物, 面积）→ 回填 result 表
  - `03_代码/Q1_结论.csv`（列：指标, 数值）

## 5. 关键公式骨架

- 集合：地块 p∈P（类型 τ(p)），季槽 k=(p,t,s)，作物 c∈C(k)（按适配规则），豆类 C_b，年份 t=2024…2030。
- 变量：x_{c,k} ≥ 0 种植面积；y_{c,k}∈{0,1} 是否种植；σ_{c,k}, σ'_{c,k} 正常/降价销量（case2）。
- 适配：x_{c,k} 仅对 c∈C(k) 定义。
- 面积：Σ_c x_{c,k} ≤ A_p　　(1-1)
- 联动：x_{c,k} ≥ m·y_{c,k}，x_{c,k} ≤ M·y_{c,k}（m=最小面积，M=地块面积）　(1-2)
- 重茬：对时间相邻季槽 (k,k')：y_{c,k} + y_{c,k'} ≤ 1 ∀c　(1-3)
- 豆类滑窗：Σ_{c∈C_b} y_{c,p,s,t∈[w,w+2]} ≥ 1，w=2024…2028　(1-4)
- 销量线性化：q_{c,k}=γ_{c,τ}·x_{c,k}；case1: σ≤q, σ≤D_c；case2: σ≤D_c, σ+σ'=q　(1-5)
- 目标：max Σ(价格·σ [+0.5·价格·σ']) − Σ成本·x　(1-6)

## 6. 求解方案（给编程手）

1. `load_data.py`：产出 `data.json`（地块、作物、适配字典、亩产量/成本/价格、D_c、2023 历史）。
2. `solve_q1.py`：建 MILP（0-1 变量约 1.1 万），HiGHS 求解；case1、case2 各一次。
3. `fill_result.py`：plan_case{1,2}.csv 回填 result*.xlsx（按 sheet 年份 + 行=地块+季次 + 列=作物名 定位）。
4. 验证：status=optimal；面积守恒与约束抽查；case2 收入 ≥ case1。

## 8. 验证方式

① HiGHS 返回 optimal；② 每季 Σx ≤ A_p 抽查；③ 豆类滑窗抽查；④ 2024↔2023 重茬抽查；
⑤ case2 收入 ≥ case1（常识校验）。

## 9. 局限与备胎

- 局限：确定性参数；分散度阈值为主观量化；A2 口径影响绝对值。
- 降级：若 MILP 超时 → 按年滚动求解（每年一个子 MILP），损失全局最优性。
