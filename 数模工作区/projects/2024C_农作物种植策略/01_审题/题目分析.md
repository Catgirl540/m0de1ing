**背景速览**：华北山村 1201 亩露地（平旱地 6 块 365 亩 / 梯田 14 块 619 亩 / 山坡地 6 块 108 亩 /
水浇地 8 块 109 亩）+ 普通大棚 16 个、智慧大棚 4 个（各 0.6 亩）；41 种作物（粮食 1–16、
蔬菜 17–37、食用菌 38–41）；2023 年实种情况与统计参数见附件2。

## 2. 约束清单

**硬约束（题目明说）**
1. 地块适配：平旱地/梯田/山坡地 → 单季粮食（水稻除外）；水浇地 → 单季水稻 或 两季蔬菜；
   普通大棚 → 第一季蔬菜+第二季食用菌；智慧大棚 → 两季蔬菜。[附件1说明列]
2. 大白菜(35)/白萝卜(36)/红萝卜(37)只能在水浇地第二季种，且该季只能种三者之一。[附件1说明(3)(4)]
3. 食用菌(38–41)只能种普通大棚第二季。[附件1说明(6)]
4. 智慧大棚不能种 35–37。[附件1说明(7)]
5. 同一地块不能连续重茬种同一作物。[题目]
6. 每个地块三年内至少种一次豆类（类型含"豆类"：1–5、17–19），2023 年起算。[题目]
7. 每季每地块：各作物面积之和 ≤ 地块面积（"每季可合种"）。
8. 软性管理要求：种植地不能太分散、单块地单作物面积不宜太小 → 需量化假设。

**隐含约束（假设，编号进论文 §3）**
- A1 销售单价为区间字符串 → 取中值。【待确认：可对区间端点做灵敏度】
- A2 预期销售量（附件未直接给出）→ 取该作物 2023 年总产量 = Σ(2023种植面积 × 对应地块类型亩产量)，
  按季封顶；2023 未种植的作物取 0（不种，除非豆类约束强制）。【待确认：主流口径之一】
- A3 分散度量化：单(作物,地块,季) ≥ 0.5 亩（露地）/ 0.3 亩（大棚）；单(作物,季) 占地块数 ≤ 8。
- A4 大棚第二季跨年（9月—次年4月）按当年归档记账。
- A5 重茬判定在时间相邻两个种植季之间（含跨年 2023→2024 交界）。
- A6 2024–2030 每年都满足全部约束（豆类三年窗为 2024–2026 … 2028–2030 六个滑窗）。

## 4. 问题树与子任务分派

```
问题一（MILP）
├─ ① 数据加载器（地块/作物/适配/参数/2023历史→JSON） → 编程手
├─ ② 模型构建（变量/约束/线性化目标）→ 建模手（模型卡片I）
├─ ③ 求解 case1/case2 + 回填 result 表 → 编程手
└─ ④ 结果图表（收入对比/面积结构）→ 论文手（图表需求单 F01–F03）
问题二
├─ ① 参数情景生成（题给区间）→ 编程手
├─ ② 中枢情景求解 + 情景稳定性统计 → 编程手
└─ ③ 风险讨论（分布图）→ 论文手
问题三
├─ ① 相关性建模（需求相关矩阵/价格联动）→ 建模手
├─ ② 蒙特卡洛 + 重优化比较 → 编程手
└─ ③ 与问题二对比结论 → 论文手
```

## 5. 方法候选与首选建议

## 6. 评委视角

- **基础得分点**：数据口径交代（区间取中值、销量推算）；Q1 完整 MILP + result 表填全；
  适配/重茬/豆类三类约束显式建模。
- **区分度**：销量线性化（σ≤q, σ≤D）正确性；豆类三年滑窗；2023→2024 交界重茬；
  Q2 不确定性可复现机制；Q3 真模拟真比较。
- **踩坑**：①销量口径不交代；②35–37 专属水浇地第二季漏建导致方案不可行；
  ③豆类窗口不滑窗；④大棚跨年季次记账混乱；⑤result 表竖排季次标签回填错位。
