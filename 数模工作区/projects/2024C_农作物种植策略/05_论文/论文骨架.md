# 论文骨架（开赛 T+2–4h 填一次，此后只做填空）

> 用法：按题目删改本骨架，每节标注预计字数与图数；写作时用 `/写章节` 按节投喂。
> 配套 Word 版：`00_标准/论文模板/CUMCM_国赛/CUMCM论文模板_官方格式_2026.docx`（官方版式已预设好）。全文目标：正文 20–25 页（不含附录），图 6–10 张。

## 0. 标题
- 句式：`基于 A 的 B 问题研究`（A=核心方法组合，B=题目领域）。避免「浅谈/探究」。

## 1. 摘要（最贵 800 字，最后写）
- 五要素：背景 1–2 句 → 每问一段（模型名+方法+**数值结论**）→ 亮点 1–2 句 → 关键词 3–5 个
- 模板：`摘要模板.md`；角色卡：`prompts/06_摘要大师.md`

## 2. 问题重述（半页）
- [ ] 背景重述（2–3 句，题目的语言）
- [ ] 各问要求逐条列出（不得改题意）

## 3. 问题分析（1 页 + 技术路线图）
- [ ] 每问分析思路：输入什么 → 用什么思路 → 输出什么
- [ ] **全文技术路线图**（`make_flowchart.py --demo route` 改 JSON）
- 图规划：图 1 = 技术路线图

## 4. 模型假设（半页）
- [ ] 6–10 条，每条：内容 + 一句合理性论证
- 来源：`02_建模/模型卡片-*.md` 的假设清单

## 5. 符号说明（半页表格）
- [ ] 三列：符号 / 含义 / 单位。**单一事实源**：新符号先入表再使用

## 6. 模型的建立与求解（正文主体，每问 3–5 页）
每问四段式：
1. 建模思路（为什么是这个模型）
2. 模型建立（公式编号 (1-x)/(2-x)，每式后解释符号）
3. 模型求解（算法步骤/伪代码 + 参数依据）
4. 结果分析（图 + 引用 + 解读三句式：现象→机理→回答题目）
- 图规划：每问 2–3 张（流程图 1 + 结果图 1–2），数据来自 `03_代码/` 输出 CSV

## 7. 敏感性分析（1–2 页）
- [ ] `make_chart.py sensitivity` 图 1–2 张 + 稳健性结论段

## 8. 模型的评价与推广（1 页）
- [ ] 优点（对应题目要求）、缺点（必配改进方向）、推广

## 9. 参考文献（≥8 条，含 1–2 条近三年文献）
## 10. 附录（核心代码，关键步骤注释对应文中公式编号）
