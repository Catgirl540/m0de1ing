# 表达句式库（国赛论文 · 平实而突出）

> 定位修正（v2）：数模论文的"创新性"不在修辞，在**问题定义得比别人准、结论给得比别人
> 具体且有边界、自我验证做得比别人足**。语言层面恰恰要求平实——标题用平实语言概括是
> 行规，破折号金句、口语比喻、悬念式开头是 AI 腔，会同时触发"文风扣分"和"原创性怀疑"
> （竞赛要求如实声明 AI 使用，文风是最好的自证）。
> 用法：写完跑 §0 两条 grep 至零命中；摘要按 §2 平实起手、§3 数值句式变换；
> "脱颖而出"靠 §12 的三件事，不靠形容词。

## 0. 两份黑名单（写完各 grep 一次，命中即改）

**A. 传统套话**（十年不变，评委跳读）：

```bash
grep -n "综上所述\|随着.*的发展\|先进的\|显而易见\|不难发现\|一定程度上\|首先\|其次" 05_论文/章节草稿.md
```

**B. AI 腔**（v1 版句式库自己就犯过，引以为戒）：

```bash
grep -n "——本文\|真金白银\|刀刃\|钱袋子\|亮出\|秘密武器\|换言之\|值得一提的是\|说白了" 05_论文/章节草稿.md
```

| AI 腔信号 | v1 反面教材 | 为什么错 |
|---|---|---|
| 新媒体悬念句 | "同样的 1201 亩，只是换个种法，七年多收 835 万元——本文解决的正是这个'怎么种'的问题" | 破折号钩子是自媒体句式，论文第一句应为对象+问题 |
| 对偶标题 | 《保口粮，也保钱袋：……》 | 标题行规是平实概括，修辞标题显得轻浮 |
| 口语比喻 | "让每一亩地都种在刀刃上""把钱袋子保住" | 拟人/口语与学术语体冲突 |
| 金句过渡 | "真正的问题从这里开始""模型在两处表现出了它的'性格'" | 每段一个金句 = AIGC 痕迹最重的特征 |
| 戏剧化设问 | "豆类轮作会把收益拉低多少？" | 全文至多一处直陈式设问，且要用句号自答 |

## 1. 标题：平实概括是行规，能做的是"精准化"

标题不追求新，追求**三秒可读**：评委扫一眼能说出对象、问题、方法。全部用陈述短语：

| 式 | 模板 | 2024C 示例 |
|---|---|---|
| 基准式 | 考虑/基于 + 核心机制 + 的 + 对象 + 问题 + 模型/优化 | 《考虑重茬与轮作约束的农作物多季种植策略优化模型》 |
| 条件式 | XX 条件/情形下 + 对象 + 研究 | 《超产两种处置情形下农作物种植方案的整数规划优化》 |
| 双段落式 | 主标题（对象问题）＋破折号限定口径 | 《农作物种植策略优化模型——以 2024—2030 年华北某村为例》 |

精准化是唯一允许的"出彩"：把泛词换成机制词——"基于智能算法的优化研究"（太空）改成
"考虑重茬、轮作与地块适配约束的多季种植混合整数规划模型"（实）。自测三问：
①三秒内说得出研究对象吗 ②方法词与正文一致吗 ③超过 25 字了吗。
不用比喻、不用设问、不用数字悬念，一般不加副标题（需要限定口径时除外）。

## 2. 摘要第一句：三种平实起法（替换悬念钩子）

1. **对象—问题式**（默认）："本文针对华北山区某乡村 2024—2030 年农作物种植方案的优化
   问题，在地块适配、禁止重茬、豆类三年轮作等约束下，建立多季种植的混合整数规划模型。"
2. **约束难点式**（点出本题特有的麻烦，仍然平实）："该村耕地分为 4 类 34 块并含 20 个
   大棚，各类地块的种植制度与轮作要求互不相同，种植方案需逐年逐季给出，本文研究该
   多周期决策问题的建模与求解。"
3. **口径式**（当题目有易错口径时）："超产部分按滞销与五折两种口径处置，是本题两种
   情形下方案差异的全部来源，本文对两种情形分别建立并求解优化模型。"

第一句的任务是让评委确认"这篇知道自己在做什么"，不是制造悬念。

## 3. 数值结论：四种句式（信息密度升级，不加戏）

| 式 | 平实写法（2024C 真实数字） |
|---|---|
| 差值式 | "五折情形七年净收益 8651.4 万元，较滞销情形 7816.4 万元高 835.0 万元（+10.7%），差值全部来自超产部分的半价回收。" |
| 反事实式 | "20 组抽样情景下收益波动不超过均值的 1.7%，参数按题给区间最不利方向变化时方案不需调整。" |
| 条件式 | "滚动重优化在参数独立波动时仅带来 0.2% 的增益；当波动含共同市场因子时增益升至 10.4%，故建议以年度为周期滚动重解。" |
| 消融式 | "去除豆类三年轮作约束后最优收益不变（78 164 150 元），该约束对本题不构成实际负担。" |

消融式是区分度最高的一种：每减一条约束重解一次，"哪条约束真正咬住了收益"是评委
很少见到的扎实结论（本次实验数据见 F06_豆类约束代价.csv）。

## 4. 建模动机：把"为什么非它不可"写足（不需要修辞）

- 模板一（变量结构式）："本题决策兼有'种不种'（0-1）与'种多少'（连续）两重性质，
  重茬、轮作等规则只与前者有关，面积分摊只与后者有关，故设 0-1 变量 y 与连续变量 x
  分工表达，构成混合整数规划。"
- 模板二（事故预防式）："若不加式(1-3)，模型会在同一地块连年安排同一作物，与题目
  '不能重茬'直接冲突；该约束是方案合法性的边界，而非求解技巧。"
- 模板三（口径决定论）："预期销售量的口径决定全部收益的上限，本文采用 2023 年产量
  口径并在假设 A2 中说明理由——口径错了，后链全部作废。"

## 5. 结果解读：三句式（现象—机理—回答）的四种平实变体

1. 结论前置："回答问题一：滞销 7816.4 万元、五折 8651.4 万元。该差值的构成见下文。"
2. 异常切入："方案在 2025 年出现一处被动轮作间隔，这是豆类三年滑窗约束的直接后果
   （图 F03），不是求解误差。"
3. 边界交代："该结论的适用条件是参数独立波动；波动相关时结论反转，见问题三。"
4. 反向解读："2023 年 F1、F2 大棚各有 0.3 亩闲置（附件 2），优化后两季制度全部占满，
   闲置产能的利用是收益提升的来源之一。"

## 6. 灵敏度/稳健性：写"有内容的判断"

- 量化判决："收益标准差为均值的 1.7%，重优化增益 0.2%——中枢方案加年度微调已接近
  最优，无需为参数波动额外设计。"
- 条件化结论："稳健性在参数独立波动时成立；波动相关时固定方案的损失放大至 10.4%，
  届时滚动重解模型应作为方案的一部分。"
- 失效边界："结论在价格区间中值口径下成立；以区间端点重跑（附录 A 命令）方向不变。"

## 7. 模型评价：缺点配改进方向的三种写法

1. 阈值承认式："'不宜太小、不能太散'以固定阈值（0.5 亩/8 地块）量化，换取模型线性
   与可解；改进方向是阈值参数化后做二维灵敏度，由使用者自行权衡规模效率与耕作便利。"
2. 口径承认式："预期销售量沿用 2023 年产量口径，是数据约束下的保守选择；若获得市场
   调研数据，仅需替换需求生成方式，模型结构不变。"
3. 预案式："若出现题面未覆盖的极端行情，第一预案是滚动重解；全部脚本可一键复现，
   方案的价值一半在结果、一半在可随时重算。"

## 9. 章节衔接：八个平实过渡件

"在这一前提下，" / "由此，" / "该结论的适用边界是，" / "这一差值的构成如下：" /
"上一节结果在本节需作一处修正：" / "就本题而言，" / "进一步的检验是，" /
"——这也是问题二的出发点。"
原则：衔接词说明**逻辑关系**（因果/转折/递进/边界），不制造悬念。

## 10. 模型命名：全称机制化，简称全文统一

- 全称：对象＋机制＋类型，如"地块×茬口×市场三层适配的混合整数规划模型"；
- 简称：取 2–6 字（"三层适配模型"），摘要首次出现给全称，此后全文（含图表、代码注释）
  统一用简称——一个稳定简称本身就是结构清晰的标志；
- 不起花名："粮仓卫士""金穗模型"这类名字属于减分项。

## 11. AI 腔自检（原创性自证）

竞赛要求声明 AI 使用情况，文风是最好的自证材料。提交前数一遍：
①破折号钩子句 ≤1 处；②口语比喻 0 处；③排比金句 0 组；④每段首句均为陈述句；
⑤"本文/本模型"出现频次正常（每千字 ≤3 次）。超标段落整段重写为陈述句。

## 12. 真正让论文脱颖而出的三件事（本库的最终答案）

1. **判断力**：结论带数字且带边界（"在题给区间内成立""独立波动时成立"）——大多数
   论文的结论没有边界，这是最便宜的区分度；
2. **验证深度**：消融实验（F06）、口径对照、独立重算、一键复现——评委很少见到，
   见到即加分；
3. **机制洞察**：把一个反直觉现象解释到底（"重优化增益从 0.2% 放大到 10.4%，差在
   波动是否相关"）。
   表达只需平实准确；以上三件事，件件都写进了正文，论文自然不落俗套。
