# 提交检查清单（G7 门禁 · 逐项勾选，全部打勾才允许提交）

> 规则类条目以**当年竞赛章程**为准；不确定的条目人工核对章程原文。

## A. 硬性格式（P0）
- [ ] 摘要独立一页、含关键词；符合当年页码/编号页要求
- [ ] 承诺书 / 编号页按当年要求放置（若为线上填写则确认编号已生成）
- [ ] 全文匿名：无姓名、学校、地区、指导教师等任何身份信息
- [ ] 页码正确；目录（可选）与正文标题一致
- [ ] PDF 在其他设备打开验证：无缺字、图不糊（字体已嵌入）
- [ ] 文件命名符合章程；大小符合上传限制；MD5（如需）已生成

## B. 图表与公式（P0）
- [ ] 图表编号连续、每张都被正文引用（对照 figure_index.csv）
- [ ] 图为 300dpi/矢量、中文正常、风格全文一致
- [ ] 表格三线表、表题在上、图题在下
- [ ] 公式编号连续且正文引用的编号真实存在
- [ ] 符号说明表与正文定义一致、无未定义符号

## C. 内容一致性（P0）
- [ ] 摘要中每个数字与正文/表格一致（逐个核对）
- [ ] 结论与结果数据一致，无正文未支撑的说法
- [ ] 参考文献 ≥ 8 条、格式统一、均被正文引用
- [ ] AI 使用声明（如当年要求）已如实撰写

## D. 结构完整性（P1）
- [ ] 每问闭环：问题 → 假设 → 模型 → 求解 → 结果 → 回答
- [ ] 敏感性分析 + 模型评价（优缺点配改进方向）存在
- [ ] 附录代码可读、与文中模型对应、无个人信息与密钥

## E. 提交动作
- [ ] 提前 ≥ 2 小时上传（防网络意外），下载回副本核验
- [ ] 全队备份终稿 PDF + 源文件 + 代码各一份
