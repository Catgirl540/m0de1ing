# 交付物标准（CUMCM 2026 · 唯一验收口径）

> 制定依据：《全国大学生数学建模竞赛论文格式规范（2026年修订稿）》
> （[官网原文](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html)）
> 与《参赛规则（2026年修订稿）》。
> 用法：任何产出完成前，AI 与论文手按本文"验收动作"逐条打勾；打不全 = 没完成。

## 1. D1 论文电子版 PDF（最核心交付物）

**定义**：单个 PDF（建议）或 Word，≤20MB，提交评阅系统。

**必备内容（按序）**：摘要专用页（第一页）→ 正文（≤30 页、无目录）→
参考文献 → 附录（支撑材料文件列表 + 全部可运行源代码）。

**验收动作**：
1. [ ] 文件 ≤20MB；
2. [ ] 第一页 = 摘要专用页，全文无承诺书、编号专用页；
3. [ ] 全文搜索：队号 / 姓名 / 学校 / 赛区 0 命中（含页眉页脚、图片、代码注释）；
4. [ ] 正文 ≤30 页且无目录页；
5. [ ] 页码自摘要页起编、页脚居中；
6. [ ] 附录代码与 `projects/<赛题>/03_代码/` 一致且完整；
7. [ ] 抽查 3 个正文数字与结果 CSV 一致；
8. [ ] 每条参考文献在正文有标注。

**存放**：`projects/<赛题>/06_交付/论文终版.pdf`

## 2. D2 摘要专用页

**定义**：论文第一页，含标题、摘要、关键词，无需英文，≤1 页。

**标准**：五要素齐——背景 1-2 句；每问"针对X问题，建立Y模型，采用Z方法，
求解得（具体数值结论）"；亮点 1-2 句；关键词 3-5 个。

**验收动作**：只读摘要能回答"做了什么、怎么做的、结果多好"；
摘要中每个数字在正文能找到且一致；
表达自查：`01_资料库/创新表达句式库.md` §0 黑名单 grep 零命中（可选加分项）。

## 3. D3 支撑材料包

**定义**：单个 RAR/ZIP，≤20MB。

**必备**：可运行源程序（官方硬性要求）+ `README.md`（环境、依赖、一键运行
命令、输出位置）+ 自查数据资料 + 大篇幅中间结果图表；不含承诺书/编号页/任何身份信息。

**验收动作**：
1. [ ] 解压到新目录，按 README 一键运行入口脚本成功；
2. [ ] 程序输出与论文结果一致（抽查 2 处）；
3. [ ] 包内文件列表 = 论文附录列表（diff 一致）；
4. [ ] 包内搜索无身份信息。

**存放**：`projects/<赛题>/06_交付/支撑材料.zip`

## 4. D4 求解代码（进支撑材料包前的门槛）

**标准**：可复现——依赖清单 `requirements.txt`、随机种子固定、输入文件齐全、
运行命令明确、输出文件名与图表需求单图号一致。

**验收动作**：新目录一键运行成功；每个结果文件能对应论文中的图/数；
**求解类产出：目标值与按解独立重算的结果一致（至少抽查 1 个指标），求解状态如实记录。**

## 5. D5 图册

**标准**：`04_图表/figs/` 内 PNG+PDF 双格式 300dpi；`figure_index.csv` 登记齐全；
每图在正文有引用与解读。

**验收动作**：`python tools/check_figures.py projects/<赛题>` 退出码 0；
过 WORKFLOW.md「审图十查」。

## 6. D6 复盘（赛后 48h 内）

**定义**：`projects/<赛题>/07_复盘/复盘.md`，按 `90_复盘/复盘模板.md` 填写；
必须含 ≥1 条改进落地。复盘不是可选项，是 D 系列交付物之一。
