# 国赛论文模板（官方格式 · Word 版）

> 依据《全国大学生数学建模竞赛论文格式规范（2026年修订稿）》
> （[官网原文](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html)）。
> 官方对字体字号不做统一要求，但页数、页码、构成、身份数据是硬条款——
> 本模板把这些硬条款直接预设好，你只管往里填内容。

## 模板文件

**`CUMCM论文模板_官方格式_2026.docx`** —— 唯一正式模板，Word 直接编辑，不依赖 LaTeX。

已按官方规范预设：

| 预设项 | 内容 |
|---|---|
| 页面 | A4，上下左右边距 2.5cm（官方第一条） |
| 第一页 | 摘要专用页（标题+摘要+关键词），页码从此页起编、页脚居中、从 1 连续（官方第二、三条） |
| 正文 | 无目录（官方第四条：正文不要目录、≤30 页） |
| 结构 | 1 问题重述 → 2 问题分析 → 3 模型假设 → 4 符号说明 → 5 建模与求解 → 6 敏感性分析 → 7 评价与推广 → 参考文献 → 附录 |
| 样式 | 正文宋体小四 1.3 倍行距首行缩进 2 字符；标题黑体；三线表；编号公式（1-1）可直接编辑 |
| 提示 | 所有灰色【提示】【请替换】文字填完后删除 |

## 用法（三步）

1. **复制进项目**：开赛建赛后模板已自动复制到 `projects/<赛题>/05_论文/论文模板_官方格式.docx`
   （或手动复制本文件）；
2. **替换占位**：在 Word 里按 `Ctrl+H` 搜「【」逐个替换占位与提示；图表用
   `插入 → 图片` 放入 `04_图表/figs/` 生成的 PNG（300dpi）；
3. **导出提交**：定稿后 `文件 → 另存为 → PDF`（≤20MB），即交付物 D1；
   支撑材料打包为 ZIP（≤20MB）即 D3。验收动作见 `00_标准/交付物标准.md`。

## 排版红线（自检）

- 正文 ≤30 页且无目录；摘要页 ≤1 页；
- 全文（含图片、页眉页脚、代码注释）搜不到队号/姓名/学校/赛区；
- 附录 A 清单 = 支撑材料 ZIP 内容；附录 B 含全部可运行源程序；
- AI 使用情况按官方《人工智能工具使用规定》如实说明。
