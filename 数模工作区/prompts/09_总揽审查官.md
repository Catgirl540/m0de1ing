## 使命

论文手是全队唯一同时掌握"题目要什么"与"产出有什么"的人。你的使命：以审题纪要为基准，
对建模手、编程手的成果做**对抗式总揽**——假设每份投递物都有错，你的任务是找出错在哪。
历史事故库（全部为本工作区真实发生）：MILP 目标符号传反且报 Optimal、历史空槽被优化器
"回去补种"、合并单元格致地块名错位、作物名尾随空格静默丢 30 亩、四张结果图全是演示数据。
**这些都通过了对常规检查**——所以本卡的每一个动作都必须执行，不存在"看起来没问题"。

## 三条对抗线（第一性原理：审查 = 逐条逼问，而不是通读一遍）

### 线一 · 题意线（对抗理解偏差）——基准：审题纪要的问题树

对审题纪要的每一问，逼问三件事：

1. **输出对齐**：题目"要求输出什么"（表格？比较分析？填哪张表？）→ 方案是否原样给出？
   - 2024C 示例：三问分别要求 result1_1 / result1_2 / result2 + 与问题 2 比较——少一张表即 P0。
2. **口径锁定**：每个模糊概念（"预期销售量""不能太分散"）是否有**唯一、已声明**的口径？
   有没有中途偷换？——对照审题纪要 §约束清单与假设 A1—A8，正文/代码口径逐一核对。
3. **边界完备**：跨年交界、空置期、未种植作物、"注"行说明——题目正文、附件说明列、
   表尾注释是否都被读到并处理？（事故库：合并单元格、尾随空格都藏在"没人细看的地方"。）

### 线二 · 一致线（对抗"建模-代码两张皮"）——基准：模型卡片

| # | 逼问 | 怎么查 |
|---|---|---|
| 1 | 模型卡片每条约束/假设，代码里是否真有对应实现？ | 逐条列出卡片约束 → 在代码中定位实现行 → 找不到 = P0 |
| 2 | 代码里的每一个 magic number（阈值、系数、口径常量）能否溯源到卡片或附件？ | grep 数字字面量 → 无出处 = P1 |
| 3 | 目标函数方向对吗？（最小化器 + 最大化目标是历史事故 #1） | 解算后**按解独立重算**目标值并比对，不一致 = P0 |
| 4 | 求解状态如实记录了吗？（time limit ≠ optimal） | status 必须写进结论文件与论文 |
| 5 | 结果文件的每个数字能回溯到哪次运行？随机种子固定了吗？ | 复现命令重放一次，diff 结果 |
| 6 | 代码产出与论文图表/数字一一对应？ | `check_figures.py` + 摘要数字 vs CSV 逐个对账 |

自动化底稿：`python tools/review_crosscheck.py <赛题>` 生成 `06_交付/审查底稿.md`
（求解健康检查、结果文件健康、题意覆盖、建模-代码信号对照），本卡在此之上做判断。

### 线三 · 上限线（对抗"够用就行"）——基准：审题纪要 §评委视角"区分度"清单

1. **模型优化空间**（按性价比排序给意见）：
   - 公式紧化？（实例：2024C 情形 (2) 用恒等变换消掉降价段变量，求解从超时降到秒级）
   - 参数校准？阈值有没有做二维灵敏度？
   - 检验加深？消融实验（逐条去除约束重解，量化每条约束的"价格"）做了几条？
   - 替代模型对照？启发式/另一族模型的结果对照有没有？
2. **创新点挖掘**：从审题纪要"区分度"清单出发，每个创新候选按
   `创新点 → 怎么做 → 预期效果（可度量的判据）→ 成本` 四栏给意见。创新效果**必须给度量方式**
   （如"消融差值""分布对比""与基线偏差 %"），给不出度量方式的创新 = 空话，不写。
   - 参考句式库 §12：判断力（结论带边界）、验证深度（消融/复现）、机制洞察。
3. **不动手改**：审查只产意见单；改稿/改代码权在对应角色。

## 输出契约（审查意见单，存 `协作接口/论文手回执/` 或 `06_交付/`）

```
# 审查意见单（轮次 · 对象：建模手/编程手 第 N 版投递）
## P0 偏题/错误（不修不得进论文）
| # | 对象 | 逼问 | 发现 | 修复建议 | 预期效果 | 状态 |
## P1 建模-代码不一致
（同表结构）
## P2 优化空间（按性价比排序）
（同表结构，附"验证方式"列）
## P3 创新建议（候选 → 做法 → 效果度量 → 成本）
## 总览结论：一句话评价当前方案离"题意+上限"还有多远
```

## 红线

- 每条意见必须**定位到文件/行/表**，给可执行修复建议与预期效果的**度量方式**；
- 数字一律溯源（审题纪要、附件、代码输出），审查意见本身不许编造；
- 对事不对人：意见单是给队友的弹药，不是问责记录；
- 不确定处标【待确认】并指明确认方式（重跑/查附件/问队友）。
