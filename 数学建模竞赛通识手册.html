一、竞赛概况与论文手角色

1.1 竞赛是什么

全国大学生数学建模竞赛（CUMCM）是中国工业与应用数学学会主办的面向全国大学生的群众性科技活动，每年9月举行，三人一队，三天三夜完成一篇包含模型建立、求解和讨论的完整论文。竞赛分本科组和专科组，题目分A题（偏连续/数学物理）、B题（偏离散/优化/数据分析）、C题（偏大数据/统计）三选一。

1.2 论文手的角色定位

三人队伍通常分工为建模手（负责数学模型设计和算法选择）、编程手（负责代码实现和数据处理）、论文手（负责论文撰写、图表制作和排版）。但这个分工不是绝对的——论文手必须全程参与建模讨论，否则无法写出有深度的论文。

论文手的核心职责：
  • 第一天：通读赛题、查阅文献、搭建论文框架（摘要→问题重述→模型假设→符号说明）
  • 第二天：同步建模进度、撰写模型建立与求解过程、制作图表
  • 第三天：完善模型检验与灵敏度分析、写模型评价与推广、精修摘要（最后2小时必须留给摘要）、排版检查
论文手最重要的认知：评委首先看摘要，如果摘要不过关，正文再好也可能被淘汰。摘要不是"最后随便写写的总结"，而是全文最核心的部分——它必须在半页纸内告诉评委"你们解决了什么问题、用了什么方法、得到什么结果、有什么创新"。

二、论文格式规范（2026年官方修订版）

以下内容依据全国大学生数学建模竞赛组委会2026年3月3日发布的最新格式规范 [官方原文]。

2.1 纸质版论文结构（共四部分）

页码内容要求
第1页承诺书所有队员签名，手写或打印均可
第2页编号专用页由赛区组委会填写，参赛队不需要填写
第3页摘要专用页含标题、关键词，整页不超过一页，页码从"1"开始
第4页起正文不要目录，不超过30页
正文之后附录页数不限，必须包含全部可运行源程序代码

2.2 八条铁律

编号规则违反后果
第1条A4纸打印，页边距至少2.5cm，左侧装订视为违规
第3条摘要不超过一页（含标题和关键词）影响评审
第4条正文不超过30页，不要目录影响评审
第5条附录必须包含全部完整可运行源代码取消评奖资格
第6条全文任何位置不得出现学校、姓名等身份信息取消评奖资格
第7条引用他人成果必须列出参考文献并标注影响评审
第9条电子版必须与纸质版完全一致，PDF或Word格式，不超过20MB影响提交
第10条电子版第一页必须是摘要（不含承诺书和编号页）影响提交
最容易踩坑的两条：
  1. 缺源码/代码不可运行 = 直接取消评奖资格。必须在附录中放全部可运行代码，包括EXCEL、SPSS的交互命令也要写。如果确实没用到程序，必须明确写"本论文没有用到程序"。
  2. 出现身份信息 = 直接取消评奖资格。包括代码注释中的作者名、文件名中的学号、图表中的学校水印——全部不能有。

2.3 电子版提交规范

  • 提交两个文件：①论文PDF/Word（≤20MB） ②支撑材料压缩包（RAR/ZIP，≤20MB）
  • 论文不要压缩，直接提交PDF
  • 支撑材料含：全部可运行源程序、自主查阅的数据、较大篇幅图表
  • 支撑材料文件列表必须在论文附录中列出

三、论文黄金结构：七段式写作框架

国赛论文遵循"七段式黄金结构"，每一段都有明确的写作目标和内容要求。

序号结构核心任务篇幅建议
1摘要全文精华浓缩：问题+方法+结果+创新点半页~一页
2问题重述用数学语言转译题目背景，明确目标与约束1-2页
3模型假设逐条列出并说明合理性（如"忽略空气阻力"需给出依据）半页
4符号说明表格列出全文所有变量符号及含义半页
5模型建立与求解核心部分：数学推导+算法实现+结果展示15-20页
6模型检验与灵敏度分析验证模型合理性，分析参数变化的影响2-3页
7模型评价与推广优缺点分析+可推广到哪些场景1-2页

3.1 各结构详细写作指南

问题重述

不是照抄题目原文，而是用你自己的数学语言重新表述。要把一个文字描述的实际问题，翻译成"已知什么、求什么、约束是什么"的数学问题。这一步做好了，后面建模才有清晰的方向。

写法示例："问题一要求在给定N个配送点和M辆车的条件下，找到使总配送成本最小的车辆调度方案。决策变量为车辆路径分配，目标函数为总运输距离，约束条件包括车辆容量限制、时间窗限制和每辆车必须返回起点。"

模型假设

每一条假设都要说明为什么可以这么假设。不能只写"假设不考虑天气影响"——要写"假设不考虑天气影响，因题目未提供气象数据且配送周期较短（3天），天气波动对单次配送影响可忽略"。

符号说明

用三列表格：符号 | 含义 | 单位。全文所有符号必须统一，不能在模型一用$x$表示距离，到模型二又用$x$表示时间。

模型建立与求解

这是论文主体，每个子问题按"建模→求解→结果"三步写：

  1. 建模：数学公式推导，从假设到模型建立的过程，要有逻辑链
  2. 求解：说明用什么算法/软件求解，给出关键求解步骤
  3. 结果：用表格和图表展示结果，并文字解读结果含义

模型检验与灵敏度分析

这是区分普通论文和优秀论文的关键。评委要看你是否验证了模型的可靠性。常见做法：

  • 改变参数值，观察结果变化幅度（灵敏度分析）
  • 与已知结果/常识对比验证
  • 误差分析：计算模型值与实际值的偏差
  • 稳定性检验：换一组数据看模型是否仍然适用

模型评价与推广

分三部分写：①优点（模型有什么亮点）②缺点（有哪些局限性）③推广（可以应用到哪些其他场景）。这一部分体现建模者的思维深度。

四、摘要写作：决定生死的半页纸

摘要黄金模板

摘要必须包含以下要素，缺一不可：

①问题背景：一句话说清针对什么问题建模
②核心方法：每个子问题用了什么模型/算法
③关键结果：每个子问题的核心数值结果
④模型特色：创新点、亮点、特别之处

4.1 摘要写作示例

本文针对XXXX问题，建立了XXX模型并进行了求解。 针对问题一，本文首先对数据进行预处理（缺失值填补/异常值剔除）， 建立了基于XXX的XXX模型。采用XXX算法求解，得到XXXX结果为 [具体数值]，该结果表明[一句话解读]。 针对问题二，在问题一的基础上，引入XXX因素，建立了XXX优化模型。 采用XXX算法（如遗传算法/蒙特卡洛模拟）求解，得到最优方案为 [具体方案]，目标函数值为[具体数值]。 针对问题三，采用XXX方法进行XXX分析，得到XXX结论。 本文模型的特色在于：①[创新点1]；②[创新点2]； ③[创新点3，如做了灵敏度分析/模型检验]。 关键词：关键词1；关键词2；关键词3；关键词4；关键词5
摘要五不准：
  1. 不准超过一页（含标题和关键词）
  2. 不准只写"本文解决了XX问题"而不给具体结果
  3. 不准出现图表（摘要纯文字）
  4. 不准出现学校、姓名等身份信息
  5. 不准用"本文采用了一些方法"这种模糊表述——必须写明具体模型名称
摘要写作顺序建议：不要一开始就写摘要！先写正文，把所有模型和结果都跑出来、写完后，最后花至少2小时专门打磨摘要。把每个子问题的最核心方法、最核心结果提炼出来，用最精炼的语言串成半页纸。

五、数学建模知识体系总览

数学建模的模型可以分为四大类，几乎所有国赛题目都可以归入其中一类或多类的组合。

模型大类核心任务典型问题常用方法
评价模型打分、排名、综合评估"哪个方案最好""评价XX的水平"AHP、熵权法、TOPSIS、模糊综合评价
预测模型根据已知数据推测未来/未知值"预测未来几年XX""推测XX趋势"回归、灰色预测、神经网络、时间序列
优化模型在约束条件下找最优方案"如何分配使成本最低""最优调度"线性/非线性规划、整数规划、动态规划、智能优化
分类聚类把数据分组或判断归属"将XX分类""判断属于哪一类"K-means、SVM、判别分析、决策树

5.1 速记口诀

  1. 打分排名：AHP主观、熵权法客观、TOPSIS综合排序
  2. 数据少猜未来：灰色预测GM(1,1)
  3. 时间一串数据预测：ARIMA时间序列
  4. 找因果、影响因素：回归分析
  5. 数据多复杂预测：BP神经网络
  6. 省钱赚钱、资源分配：线性/非线性规划
  7. 车辆人员选址排班：整数规划
  8. 自动分组归类：K-means聚类
  9. 两点最短路：Dijkstra算法
  10. 复杂大坑最优解：遗传算法

六、评价模型：打分排名怎么做

评价模型是国赛最常考的模型类型之一，B题和C题中大量出现"评价""排序""综合评估"的要求。

方法一句话理解数据需求适用场景优缺点
层次分析法（AHP）主观打分拆指标算权重少（无需大量数据）校园食堂满意度、供应商排序+简单易懂；-主观性强，一致性可能不通过
熵权法纯客观，靠数据差异自动算权重多（需大量统计）各省经济发展水平评价+客观无偏；-无法反映指标重要性
TOPSIS法算方案与最优/最差解的距离排序中/多地区宜居排名、车型对比+直观；-对异常值敏感
模糊综合评价用模糊隶属度处理"比较好""还行"等模糊评价少服务质量评价、风险等级评估+处理模糊信息；-隶属度函数选择主观
灰色关联分析算各方案与参考序列的关联度排序少方案优选、因素影响分析+小样本可用；-参考序列选择影响大
国赛常见组合：AHP（主观定权重）+ 熵权法（客观定权重）→ 组合权重 → TOPSIS排序。这种"主客观组合+TOPSIS"的写法在国赛中非常常见且容易得高分，因为它兼顾了主观经验和客观数据。

6.1 AHP层次分析法操作步骤

  1. 建立层次结构：目标层→准则层→方案层
  2. 构造判断矩阵：两两比较各指标重要性（1-9标度法）
  3. 计算权重：求判断矩阵最大特征值对应的特征向量
  4. 一致性检验：计算CR = CI/RI，CR<0.1则通过
  5. 层次总排序：计算各方案的综合得分
CI = (λmax - n) / (n - 1)，CR = CI / RI，当 CR < 0.1 时一致性可接受

七、预测模型：猜未来用什么方法

方法一句话理解数据需求适用场景关键要点
灰色预测GM(1,1)数据少也能预测少（≥4个）粮食产量、用电量预测需做后验差检验（P值和C值）
回归分析找变量因果关系+预测多房价因素分析、气温对销量需检验R²、P值、残差分析
BP神经网络黑箱模型自动拟合多（大）客流量、污染物浓度预测需划分训练集/测试集，防过拟合
ARIMA时间序列处理随时间变化的数据多（连续）历年GDP、每月降雨量需做平稳性检验（ADF）和差分
马尔可夫链状态转移概率预测中股市走势、天气状态转移需满足无记忆性假设
选择决策：
  • 数据只有4-10个 → 灰色预测
  • 数据多且有明确影响因素 → 回归分析（多元线性回归/非线性回归）
  • 数据多但关系复杂、非线性 → BP神经网络
  • 数据是时间序列（按月/年排列） → ARIMA
  • 需要预测状态转移 → 马尔可夫链

7.1 灰色预测GM(1,1)操作步骤

  1. 累加生成：对原始序列X⁽⁰⁾做一次累加生成X⁽¹⁾
  2. 构造矩阵：建立白化微分方程 dx⁽¹⁾/dt + ax⁽¹⁾ = b
  3. 参数估计：最小二乘法求a和b
  4. 预测公式：x̂⁽¹⁾(k+1) = [x⁽⁰⁾(1) - b/a]·e⁻ᵃᵏ + b/a
  5. 累减还原：x̂⁽⁰⁾(k+1) = x̂⁽¹⁾(k+1) - x̂⁽¹⁾(k)
  6. 后验差检验：计算后验差比值C和小误差概率P
精度等级判定：P>0.95且C<0.35为优（一级）；P>0.80且C<0.50为合格（二级）

八、优化模型：找最优解的工具箱

优化模型是国赛A题和B题的核心。几乎每年都有"如何分配""如何调度""如何安排"的问题，本质都是在约束条件下求最优解。

方法一句话理解适用场景求解工具
线性规划（LP）变量关系为直线，求最大/最小值工厂原料分配、运输运费最少MATLAB linprog / Python PuLP
非线性规划（NLP）变量关系非直线，约束更复杂电网功率调度、投资组合优化MATLAB fmincon / Python scipy
整数规划（IP）结果必须是整数（人、车、设备数）救护车站点选址、人员排班MATLAB intlinprog / Gurobi
0-1规划决策只有"选/不选"两种选址问题、背包问题、投资选择MATLAB bintprog / Gurobi
动态规划（DP）拆大问题为小问题，分阶段求最优最短路径、背包问题、多年投资手推+代码实现
多目标规划同时优化多个目标成本最低+效率最高+风险最小加权求和法/Pareto最优/NSGA-II
遗传算法（GA）模仿生物进化暴力搜索最优解NP-hard问题、复杂组合优化MATLAB ga / Python DEAP
模拟退火（SA）模仿金属退火过程搜索最优旅行商问题（TSP）、调度优化Python scipy.optimize
粒子群算法（PSO）模仿鸟群觅食搜索最优连续空间优化、参数调优Python pyswarm
优化模型写作要点：必须明确写出三要素：①决策变量是什么 ②目标函数是什么 ③约束条件是什么。这是评委评分的基本依据。即使最后用启发式算法求解，也要先建立数学规划模型。

8.1 线性规划标准写法

决策变量：设 xᵢⱼ 表示第i辆车分配到第j个配送点的货物量 目标函数：min Z = Σᵢ Σⱼ cᵢⱼ · xᵢⱼ （总运输成本最小） 约束条件： (1) Σⱼ xᵢⱼ ≤ Qᵢ （车辆容量约束） (2) Σᵢ xᵢⱼ ≥ dⱼ （需求满足约束） (3) xᵢⱼ ≥ 0 （非负约束）

九、分类聚类模型：分组归类的方法

方法类型一句话理解适用场景
K-means聚类无监督自动把相似数据分K堆省份发展水平分群、客户分群
系统聚类（层次聚类）无监督从个体合并相似项，出树状图植物品种分类、城市层级划分
SVM支持向量机有监督找最优超平面分类文本分类、图像识别
判别分析有监督已知类别判断新样本归属地震等级判别、肿瘤良恶性
逻辑回归有监督二分类问题（是/否）是否违约、是否患病预测
决策树/随机森林有监督树形规则分类客户流失预测、信用评估

9.1 分类模型评价指标

指标含义使用场景
Accuracy（准确率）正确预测占比数据类别均衡时
Precision（精确率）正确预测正类占所有预测正类的比例关注误报控制
Recall（召回率）正确预测正类占实际正类的比例关注漏报
F1值Precision与Recall的调和平均综合衡量性能
ROC/AUC不同阈值下TPR与FPR曲线及面积类别不平衡场景

十、图论与其他模型

10.1 图论模型

算法一句话理解适用场景
Dijkstra算法求两点间最短路径快递配送最短路线、景区游览路径
Floyd算法一次性算所有点间最短距离城市间交通路网最短路径
最大流最小费用网络运输求最大运量+最低成本管网输水、物流货运调度
最小生成树用最小成本连通所有节点网络布线、管道铺设
旅行商问题（TSP）访问所有点再回到起点的最短路径配送路线规划、巡检路线

十一、算法选择决策树

拿到题目后，如何快速判断用什么方法？按照以下决策路径选择：

第一步：判断问题类型

  • 题目要求"评价/排序/打分" → 评价模型（AHP+熵权法+TOPSIS）
  • 题目要求"预测/估计/推测" → 预测模型（看数据量选具体方法）
  • 题目要求"最优/最大/最小/安排/分配" → 优化模型（看约束类型选具体方法）
  • 题目要求"分类/分群/判别" → 分类聚类模型（看有无标签选具体方法）
  • 题目涉及"路径/网络/连通" → 图论模型

第二步：判断数据特征

  • 数据量很少（<10个） → 灰色预测、AHP、模糊评价
  • 数据量中等、有明确影响因素 → 回归分析、熵权法
  • 数据量大、关系复杂 → 神经网络、随机森林、深度学习
  • 数据是时间序列 → ARIMA、指数平滑

第三步：判断约束特征（优化类）

  • 变量和约束都是线性的 → 线性规划
  • 变量必须整数 → 整数规划 / 0-1规划
  • 关系非线性 → 非线性规划
  • 多阶段决策 → 动态规划
  • 问题太复杂（NP-hard） → 遗传算法/模拟退火/粒子群
  • 多个目标要同时优化 → 多目标规划（加权/Pareto/NSGA-II）

12.2 优秀论文的共同特征

  1. 摘要精炼有力：一页纸内说清问题、方法、结果、创新点
  2. 模型有"改进"或"创新"：不是直接套标准模型，而是在标准模型基础上做改进（如改进遗传算法、加权组合评价等）
  3. 结果有图表支撑：大量使用可视化图表（折线图、热力图、箱线图等）展示结果
  4. 做了灵敏度分析：分析参数变化对结果的影响，体现模型的稳定性
  5. 代码完整可运行：附录中代码结构清晰、有注释、可直接运行
  6. 排版整洁规范：公式编号统一、图表有编号和标题、符号全文统一

12.3 如何获取优秀论文

  • 官方发布：全国大学生数学建模竞赛官网 每年会发布部分获一等奖论文
  • 书籍：西安电子科技大学出版社《数学建模竞赛优秀论文选》收录近十年一等奖和美赛特等奖论文
  • 国防工业出版社《全国大学生数学建模竞赛赛题与优秀论文评析》
  • 网络资源：CSDN、知乎、B站上有大量获奖论文分享和解析

十三、论文写作技巧与排版规范

13.1 公式排版

  • 所有公式统一编号，如(1)、(2)、(3)，右对齐
  • 引用公式时用"由式(3)可知..."
  • 长公式可分多行排版，在+、-号处换行
  • 推荐使用MathType或Word自带公式编辑器
  • LaTeX用户用 \begin{equation} \end{equation} 环境

13.2 图表规范

要素要求
编号全文统一编号：图1、图2...；表1、表2...
标题图标题在图下方，表标题在表上方
引用正文中必须引用每个图表："如图3所示""结果见表2"
质量图表清晰、分辨率高，坐标轴有标签和单位
配色避免红绿色盲不友好配色，推荐蓝-橙-灰系

13.3 参考文献格式

[1] 作者. 文章标题[J]. 期刊名, 年份, 卷(期): 起止页码. [2] 作者. 书名[M]. 出版地: 出版社, 年份. [3] 作者. 论文题目[D]. 学位授予单位, 年份. [4] 网页作者. 网页标题[EB/OL]. (发布日期)[引用日期]. URL.

13.4 写作语言风格

  • 用第三人称客观叙述："本文建立了...""模型求解得到..."，不用"我/我们"
  • 用学术书面语，不用口语化表达
  • 每个结论都要有数据支撑，不能只说"结果较好"
  • 段落之间有逻辑过渡："在此基础上...""考虑到上述因素..."

十四、常见致命错误清单

错误类型表现后果如何避免
