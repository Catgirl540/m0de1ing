# C题提交材料说明

## 一、目录内容

### 结果文件

- result1.xlsx：问题一完整计划购电策略
- result2.xlsx：问题二计划购电、充放电和紧急购电结果
- result3.xlsx：问题三计划购电、调整购电、充放电和紧急购电结果
- result4-2.xlsx：波动电价下对应问题二的完整结果
- result4-3.xlsx：波动电价下对应问题三的完整结果

其中，result2.xlsx 至 result4-3.xlsx 的结果日期均为 2025-02-01 至 2025-12-31，共 334 天，符合题目附件5的填写范围。

### 程序代码

- one.py：问题一，傅里叶—Haar小波负荷拟合、截断幂正弦光伏拟合与线性规划
- two.py：问题二，严格前向负荷预测、贝叶斯参数轨迹、报童安全裕度与48小时滚动线性规划
- three.py：问题三，多时点光伏预报、负荷在线偏差修正与MPC-LP
- four.py：问题四，动态电价预测以及问题4-2、问题4-3求解
- requirements.txt：Python依赖版本

## 二、运行环境

- Python 3.12或更高版本
- numpy 2.5.3
- scipy 1.18.1
- openpyxl 3.1.5

安装依赖：

```bash
python -m pip install -r requirements.txt
```

## 三、复现所需文件结构

复现时请将“程序代码”目录内的4个Python文件和requirements.txt复制到运行根目录，并在该运行根目录下放置赛事提供的“C题/附件”目录。四个程序应放在同一项目根目录，并使用赛事提供的附件和结果模板：

```text
项目根目录/
├─ one.py
├─ two.py
├─ three.py
├─ four.py
├─ requirements.txt
└─ C题/
   └─ 附件/
      ├─ csv/
      │  ├─ 附件1.csv
      │  ├─ 附件2_小区负载.csv
      │  ├─ 附件2_光伏发电实际功率.csv
      │  └─ 附件3.csv
      ├─ 附件4.xlsx
      └─ 附件5/
         ├─ result1.xlsx
         ├─ result2.xlsx
         ├─ result3.xlsx
         ├─ result4-2.xlsx
         └─ result4-3.xlsx
```

## 四、运行顺序

```bash
python one.py
python two.py
python three.py
python four.py
```

正式运行默认使用已经通过严格前向贝叶斯优化确定并冻结的参数轨迹。若只需复现论文与提交表格，无需重新执行耗时的贝叶斯寻优。

运行前应关闭Excel中已打开的result文件，否则Windows可能因文件占用而无法覆盖工作簿。
